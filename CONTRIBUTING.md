# Contributing guidelines

> [!IMPORTANT]
> No LLM / No generative AI policy. This means:
>
> - Do not generate issues using LLMs.
> - Do not use LLMs for patches / pull requests.
> - Do not submit LLM-generated comments on the issue tracker.

If you have found a bug in **tomato** or would like a feature added, please open an issue. In case of a bug, please zip and attach the **tomato** log files.

For further contributing instructions, see:

- developer documentation for [**tomato** package](https://dgbowl.github.io/tomato/main/develop_tomato.html)
- developer documentation for [**tomato** drivers](https://dgbowl.github.io/tomato/main/develop_driver.html)
